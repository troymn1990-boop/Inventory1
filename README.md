# منصة إدارة المخزون وتقارير الأرباح (مع مزامنة bol.com)

منصة كاملة (Backend + Frontend + قاعدة بيانات) لإدارة أكتر من 500 صنف، تتبع الأرباح، ومزامنة المخزون والطلبات مع bol.com Retailer API.

## المميزات
- **نظام شجرة/متغيرات:** منتج أساسي واحد بمخزون مشترك، وأكتر من EAN (عرض على bol.com) مرتبط بيه، كل EAN بسعره الخاص - مثالي لو نفس المنتج ليه أكتر من عرض بأسعار مختلفة
- إدارة كاملة للمنتجات والـ EANs المرتبطة (إضافة / تعديل / حذف / استيراد CSV جماعي)
- بحث وترقيم صفحات يتحمل آلاف الأصناف
- تقارير أرباح تفصيلية (يومي، حسب المنتج، حسب الفترة) + رسم بياني
- تنبيهات نقص المخزون
- **استيراد تلقائي** لكل عروضك الحالية من bol.com (بالمطابقة على EAN/SKU)
- **مزامنة يدوية** (فردية لكل منتج، أو جماعية لكل المنتجات) تبعت السعر والمخزون والـ SKU لكل الـ EANs المرتبطة
- مزامنة تلقائية كل 5 دقايق مع bol.com:
  - بتسحب الطلبات الجديدة وتنزّل من المخزون المشترك للمنتج الأساسي
  - بتبعت المخزون المحدّث لكل الـ EANs المرتبطة بعد كل عملية بيع
- تسجيل دخول محمي بكلمة سر

---

## فهم نظام الشجرة

المنصة مبنية على فكرة "منتج أساسي" (شجرة) بيحمل المخزون الحقيقي، وتحته أكتر من "EAN" (عرض على bol.com):

```
سخان مياه كهربائي 50 لتر  (SKU: HEATER-001, المخزون: 40 وحدة)
 ├─ EAN 8712345678901 → Offer ID abc123 → السعر 1299.99€
 ├─ EAN 8712345678902 → Offer ID abc124 → السعر 1349.99€
 └─ EAN 8712345678903 → Offer ID abc125 → السعر 1279.50€
```

- البيع من أي EAN من التلاتة بينزّل من نفس الـ 40 وحدة
- المزامنة بتبعت نفس رقم الـ 40 (أو الرقم المتبقي) لكل الـ 3 EANs مع بعض
- كل EAN محتفظ بسعره الخاص

من تاب **المخزون**، اضغط زرار **🔗** جنب أي منتج عشان تضيف/تعدّل/تمسح الـ EANs المرتبطة بيه.

---

## دعم أكتر من حساب bol.com

لو عندك أكتر من حساب بائع على bol.com، روح تاب **"حسابات bol.com"** وضيفهم كلهم (كل واحد بالـ Client ID/Secret بتاعه). بعد كده، لما تضيف أي EAN لمنتج، تقدر تحدد أي حساب من الحسابات دي هو صاحب الـ EAN ده.

**المخزون هيفضل واحد مشترك** بين كل الـ EANs بتاعة كل الحسابات المرتبطة بنفس المنتج الأساسي - يعني لو نفس المنتج ليه عرض على حسابين مختلفين، البيع من أي حساب هينزّل من نفس المخزون، والمزامنة هتبعت الرقم المتبقي لكل الحسابات مع بعض.

الاستيراد التلقائي من bol.com (زرار "استيراد المنتجات من bol.com") بيشتغل على حساب واحد في المرة - اختار الحساب من القائمة قبل ما تضغط الزرار، وكرر العملية لكل حساب لو عندك أكتر من واحد.

## الخطوة 1: احصل على بيانات API من bol.com

1. سجّل دخول على [حساب البائع بتاعك على bol.com](https://partnerplatform.bol.com)
2. روح على **Instellingen (الإعدادات) → API Instellingen**
3. سجّل بيانات "المسؤول التقني" واحفظها
4. تحت "Client credentials for the Retailer API" اضغط **Aanmaken (إنشاء)**
5. هيديك **Client ID** و **Client Secret** — احفظهم، هتحطهم بعد النشر من تاب "حسابات bol.com" جوه المنصة نفسها (مش محتاج تحطهم كمتغيرات بيئة)
6. لو عندك أكتر من حساب بائع على bol.com، كرر الخطوات دي لكل حساب

---

## الخطوة 2: انشر المشروع (بدون أي خبرة برمجة) عبر Render.com

1. اعمل حساب مجاني على [render.com](https://render.com)
2. ارفع مجلد المشروع ده على حساب [GitHub](https://github.com) (لو مش عندك حساب، اعمل واحد مجاني وارفع المجلد كـ "repository" جديد — فيه شروحات فيديو كتير بالعربي على يوتيوب لو الخطوة دي غريبة عليك)
3. في Render، اضغط **New → Web Service** واختار الـ repository اللي رفعته
4. في الإعدادات:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. تحت **Environment Variables** ضيف القيم دي (من ملف `.env.example` المرفق):
   - `ADMIN_USERNAME` = admin (أو أي اسم تحبه)
   - `ADMIN_PASSWORD` = كلمة سر قوية تختارها
   - `JWT_SECRET` = أي نص عشوائي طويل
   - `NODE_ENV` = production
   - (بيانات bol.com بقت بتتضاف من داخل المنصة نفسها بعد النشر، مش هنا)
6. مهم: من تبويب **Disks** في Render، ضيف **Persistent Disk** واربطه بمسار `/opt/render/project/src/data` — عشان قاعدة البيانات ماتتمسحش كل ما السيرفر يعيد التشغيل
7. اضغط **Deploy** واستنى دقايق لحد ما يخلص

بعد ما يخلص، هيديك رابط زي `https://your-app.onrender.com` — ده رابط منصتك.

---

## الخطوة 3: أول استخدام

1. افتح الرابط بتاع المنصة
2. سجّل دخول بـ `ADMIN_USERNAME` / `ADMIN_PASSWORD` اللي حطيتهم
3. روح تاب **"حسابات bol.com"** وضيف حسابك (أو حساباتك) بالـ Client ID/Secret من الخطوة 1
4. عندك 3 طرق تضيف بيها منتجاتك:
   - **يدويًا:** ضيف المنتج الأساسي، وبعدين اضغط 🔗 وضيف الـ EANs المرتبطة بيه واحد واحد
   - **استيراد CSV:** شوف `sample-products.csv` المرفق - لاحظ إزاي نفس الـ `sku` بيتكرر في أكتر من صف لإضافة أكتر من EAN لنفس المنتج
   - **استيراد تلقائي من bol.com:** من تاب "المزامنة" اضغط "استيراد المنتجات من bol.com" وهيسحبلك عروضك الحالية (لكن من غير أسماء المنتجات - هتحتاج تكتبها بعد كده)
5. المزامنة التلقائية (كل 5 دقايق) بتسحب الطلبات وتحدّث المخزون بس. لو عايز تفرض تحديث فوري للسعر أو الـ SKU كمان، استخدم زرار 🔄 الفردي جنب أي منتج، أو "مزامنة الكل مع bol.com" فوق الجدول

## ملاحظات مهمة

- **مفيش استضافة مجانية دايمة 100%:** الخطة المجانية في Render بتـ"تنام" لو محدش استخدمها لفترة، وبتاخد ثواني تصحى تاني. لو عايز أداء مستمر بدون توقف، هتحتاج خطة مدفوعة (تبدأ من حوالي $7/شهر).
- **نسخة الـ API:** bol.com بتحدّث نسخة الـ Retailer API بين وقت وتاني. لو ظهر خطأ في المزامنة، راجع [توثيق bol الرسمي](https://api.bol.com/retailer/public/Retailer-API/) وعدّل `BOL_API_VERSION` في متغيرات البيئة.
- **الأمان:** غيّر `ADMIN_PASSWORD` و `JWT_SECRET` لقيم قوية وماتشاركهمش مع حد. متسيبش ملف `.env` يترفع على GitHub (ملف `.gitignore` المرفق بيمنع ده تلقائيًا).
- **النسخ الاحتياطي:** قاعدة البيانات ملف واحد (`data/store.db`). خد نسخة منه بشكل دوري.

## التشغيل المحلي (لو عايز تجرب على جهازك قبل النشر)

```bash
npm install
cp .env.example .env
# افتح .env واملأ القيم
npm start
```

هتفتح المنصة على `http://localhost:3000`
